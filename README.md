# ORVEX

Landing page for ORVEX: custom YouTube thumbnails, designed by hand.

## Structure

```
index.html          main page
css/style.css       all styles
js/main.js          thumbnail reel, scroll progress, reveal animations
images/             logos
images/thumbs/      portfolio thumbnails (.webp)
```

Plain static site. No build step, no dependencies. Fonts load from Google Fonts.

## Run locally

Open `index.html` in a browser.

## Deploy on GitHub Pages

1. Upload all files and folders in this project to the root of a GitHub repository (keep the `css`, `js` and `images` folders).
2. Repo **Settings > Pages** > **Deploy from a branch** > branch `main`, folder `/ (root)` > Save.
3. The site goes live at `https://<username>.github.io/<repo-name>/`.

All asset paths are relative, so it works under the repo sub-path.
